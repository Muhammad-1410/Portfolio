Core Engineering

Technical Architecture & Capabilities

Local Whisper Speech-to-Text

Runs OpenAI Whisper locally for speech recognition, generating millisecond-precise timestamped word and segment arrays that serve as the backbone for transcript search and caption syncing.

Dynamic Aspect-Ratio Cropping

Utilizes FFmpeg hardware-accelerated filtergraphs to transform horizontal 16:9 video into 9:16 vertical (Shorts, Reels, TikTok) and 1:1 square formats with zero letterboxing distortion.

Kinetic Word-Pop Subtitles

Generates styled Advanced SubStation Alpha (ASS) and SRT caption tracks. Features animated 1-word-at-a-time pop highlights, customizable neon swatches, and punchy display typography.

Audience Replay Heatmap Mining

Pulls YouTube's viewer re-watch graph and analyzes peaks to detect the most engaging moments automatically, pairing heatmap data with speech hooks for viral clip selection.

Non-Blocking Job Tracker

Executes heavy FFmpeg video rendering and Whisper transcription in decoupled background worker threads, allowing the frontend to poll job progress cleanly via REST APIs.

Terminal Quickstart

Installation & Execution

Running Clipper Locally 

# 1. Clone the repository
git clone https://github.com/Muhammad-1410/Clipper.git
cd Clipper

# 2. Create and activate virtual environment
python -m venv .venv
.\.venv\Scripts\activate   # Windows
# source .venv/bin/activate # macOS/Linux

# 3. Install core dependencies
pip install -r requirements.txt

# 4. Verify system checks & run automated test suite (92 tests)
python manage.py check
python manage.py test clipper

# 5. Launch Django development server
python manage.py runserver 127.0.0.1:8000

# Open http://127.0.0.1:8000 in your browser
