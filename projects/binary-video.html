binvid — Binary ASCII Video Processing Engine

A high-performance Python video processing engine and interactive Gradio 6 web application that transforms standard video footage into dynamic binary ASCII art (0s and 1s) matching scene colors and luminance at real-time speeds (>30 FPS at 1080p).

Core Engineering

Technical Architecture & Capabilities

Vectorized NumPy Compositing

Renders frames in ~11ms through vectorized glyph array slicing (atlas[digits]) and pre-allocated in-place memory buffer arithmetic, bypassing costly CPU draw calls.

Aspect-Ratio Geometry Correction

Calculates cell grids compensating for non-square font dimensions ($\text{rows} = \text{round}(\text{cols} \times \frac{H}{W} \times \frac{cell\_w}{cell\_h})$) to ensure distortion-free 16:9 output.

Pre-Rendered Glyph Atlas

Rasterizes TrueType glyphs '0' and '1' once at boot into an optimized (2, cell_h, cell_w) NumPy uint8 tensor, enabling instantaneous O(1) character lookups.

Streaming FFmpeg Pipe Sink

Pipes raw uncompressed BGR frames directly into an FFmpeg subprocess stdin stream with libx264 encoding and automatic source audio track remuxing.

Sub-15ms Live Web Preview

Gradio 6 glassmorphic interface extracts and caches keyframes in RAM; parameter adjustments re-render live in memory in under 15ms without touching disk.

Standalone Windows EXE & CLI

Compiled via PyInstaller into a standalone zero-dependency executable (binvid.exe) alongside an intuitive command-line interface with rich progress meters.

Terminal Quickstart

Installation & Execution

Running binvid Locally 

# 1. Clone the repository
git clone https://github.com/Muhammad-1410/Bin-vid.git
cd Bin-vid

# 2. Setup virtual environment & install dependencies
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
pip install -e .

# 3. Launch interactive Gradio 6 Web App
python run_app.py --inbrowser

# 4. Or convert directly via Command Line
binvid input.mp4 -o output.mp4 --mode mono --digit-mode scroll --scanlines
