Employee Activity Tracker

A Python desktop application built with PyQt5 designed to help management monitor workplace activity, detect idle time thresholds, record event screenshots, and dispatch email reports automatically.

Key Capabilities

Inactivity Threshold Monitor

Monitors user activity intervals in seconds via QLCDNumber displays and customizable idle threshold spinboxes.

Automated Screenshot Capture

Triggers silent screen captures when idle events exceed threshold boundaries, logging image timestamps in local storage.

SMTP Email Dispatch

Includes built-in email notification module transmitting encrypted activity summaries and attached screenshots to supervisors.

Windows System Toast Alerts

Integrates native Windows OS notifications using `winotify` to alert employees before logging an idle violation event.
