Crypto Technical Analysis & DCA Tracker

A financial analytics dashboard that detects 15-minute Fair Value Gap (FVG) institutional market imbalances and simulates automated Dollar-Cost Averaging (DCA) strategies inside a glassmorphic UI.

⚡ Project Overview & Key Features

The Cryptocurrency Technical Analysis & DCA Tracker combines advanced technical market structure analysis with automated dollar-cost averaging backtesting logic. Built with a Python & Django backend and styled using pure CSS Glassmorphism, it provides traders and investors with clear visualization of market liquidity imbalances and accumulation performance.

📈 Fair Value Gap (FVG) Engine

Analyzes 15m OHLCV price action to detect 3-candle institutional demand and supply imbalances. Calculates mitigation fill percentages in real time.

💰 Automated DCA Calculator

Simulates recurring asset accumulation across BTC, SOL, and ETH. Computes average cost, total invested capital, current portfolio value, and net ROI %.

🔮 Glassmorphic UI / UX

Translucent frosted-glass cards over a deep navy-purple gradient backdrop, hardware-accelerated backdrop-filter: blur(14px), and high-contrast text.

📊 Mathematical & Algorithmic Foundation

1. Bullish Fair Value Gap Condition

High(Candle 1) < Low(Candle 3) ⇒ Bullish Imbalance Range = [ High(Candle 1), Low(Candle 3) ]

When buying pressure is extremely aggressive, price skips matching bids. Price often retraces back into this shaded zone to "fill" or "mitigate" the imbalance before continuing upward.

2. Strategy ROI Formula

ROI (%) = [ (Current Portfolio Value - Total Capital Invested) / Total Capital Invested ] × 100
