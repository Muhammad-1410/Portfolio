Core Architecture

Key Capabilities

Student Governance

Complete student lifecycle management including demographic profiling, STU ID assignment, grade level placement, and attendance recording.

Real-Time Result Grading

Automated grade calculation, GPA computation, and HTMX score-to-grade evaluation with dynamic UI updates without page reloads.

Fee Invoicing & Receipts

Automated tuition fee invoice generation, status tracking (Paid/Pending), fee collection logs, and audit trails persisted in MS SQL Server.

MSSQL Enterprise Integration

Robust connection with MS SQL Server using ODBC Driver 18, ensuring transactional integrity and high-performance querying for administrative reports.
