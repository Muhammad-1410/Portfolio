# Muhammad Butt — Developer Portfolio

A responsive, fast, and visually striking personal developer portfolio website showcasing full-stack projects, Python & Django expertise, and freelance services.

## 🚀 Quick Links
- **Documentation:** See [`PROJECT_FEATURES.md`](PROJECT_FEATURES.md) for full architectural documentation, custom 404 setup, SEO/meta suite breakdown, and feature checklists.
- **Sitemap:** [`sitemap.xml`](sitemap.xml)
- **Robots Config:** [`robots.txt`](robots.txt)

## 🛠️ Built With
- **HTML5** — Semantic structure, Open Graph & Twitter Cards, JSON-LD Schema
- **Vanilla CSS3** — Neo-Brutalist design system with Google Fonts (`Plus Jakarta Sans`, `Space Grotesk`)
- **Vanilla JavaScript** — Typewriter animation, scroll reveal (`IntersectionObserver`), mobile menu, dynamic year calculation
- **React / JSX** — [`components/ClickSpark.jsx`](components/ClickSpark.jsx) for dynamic click particle animations

## 📁 Project Structure
- `index.html` — Landing page hub
- `404.html` — Custom 404 error page
- `projects/` — Dedicated project case studies
- `components/` — React / UI components
- `images/` — Media assets & favicons
- `script.js` & `style.css` — Core interactivity & design system

## 💻 Local Usage
Open `index.html` in any web browser or serve locally using VS Code Live Server or python HTTP server:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.
